# Navigation and rescue update

- Removed temporary product labels and the Individual/Organization selection. New sign-ups use a single account form. Existing stored account metadata remains readable for compatibility, but account-type fields and badges are no longer shown.
- Added Adopt, Rehome, and Rescue quick actions on Home, plus rescue links from Welcome and Profile. Profile links now use separated, rounded cards. The four-tab navigation remains consistent.
- Added Contact for Rescue with external public resources, launch-failure/copy-link handling, and a validated clipboard message composer. No request is sent automatically; no affiliation or guaranteed rescue is implied.
- Public contacts were chosen per the user's preference and checked on 19 September 2026: [Pawssion Project FAQ and assistance guidance](https://pawssionproject.org.ph/faqs/), [PAWS contact information](https://paws.org.ph/contact/).
- The local repository is unchanged. Concise disclosures about local saves, disconnected authentication/delivery, and session-only files remain at the points where users need them.
- Historical implementation notes describe the previous account-type interface; this update supersedes those UI decisions.
